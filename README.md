# Oral Cancer Classifier (Swin Transformer)

Flask web app that classifies oral cavity images as CANCER or NON CANCER.
For demonstration and learning purposes only, not for medical use.

## Setup
1. Download the `swin_oral_model` folder from <your Google Drive link> and put it next to `app.py`.
2. `pip install -r requirements.txt`
3. `python app.py`
4. Open http://127.0.0.1:5000
